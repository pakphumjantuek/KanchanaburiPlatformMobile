# Kanchanaburi Platform Mobile

แอปมือถือของ **Kanchanaburi Platform** แพลตฟอร์มดิจิทัลยกระดับคอนเทนต์ท้องถิ่นและเศรษฐกิจสร้างสรรค์ของจังหวัดกาญจนบุรี รวมตลาดสินค้าชุมชน ระบบสั่งซื้อและชำระเงิน เข้ากับเนื้อหาท้องถิ่นและแผนที่ พัฒนาด้วย Flutter ใช้งานคู่กับ backend ใน repo [KanchanaburiPlatform](https://github.com/pakphumjantuek/KanchanaburiPlatform)

## แอปนี้ทำอะไรได้

| กลุ่มงาน | สิ่งที่ทำได้ |
|---|---|
| **เนื้อหาท้องถิ่น** | อ่านเนื้อหา ดูแผนที่ตำแหน่งแบบโต้ตอบ ดูวิดีโอ YouTube และสร้างหรือแก้ไขเนื้อหาของตนเอง |
| **ร้านค้าและสินค้า** | ดูรายการร้าน ข้อมูลร้านพร้อมแผนที่ รายการสินค้า รายละเอียดสินค้า และดีลส่วนลด |
| **ตะกร้าและสั่งซื้อ** | ใส่ตะกร้า สั่งซื้อ ติดตามสถานะและรายละเอียดคำสั่งซื้อ |
| **ชำระเงิน** | ชำระด้วยบัตรผ่าน Stripe หรือโอนเงิน/PromptPay แล้วอัปโหลดสลิปให้ผู้ดูแลตรวจสอบ |
| **โปรไฟล์** | แก้ไขโปรไฟล์ รายการโปรด ประวัติการเข้าชม และเนื้อหาของฉัน |
| **ผู้ขาย** | สมัครเปิดร้าน (รออนุมัติ) แดชบอร์ดร้าน จัดการสินค้า คำสั่งซื้อ ดีลส่วนลด และส่งออกข้อมูล |
| **ผู้ดูแลระบบ** | แดชบอร์ด ตรวจสลิปและจัดการคำสั่งซื้อ ติดตามการจ่ายเงินให้ร้านค้า จัดการร้านค้า เนื้อหา หมวดหมู่ แท็ก กำหนดการ รายงานและส่งออกข้อมูล |

## เทคโนโลยีที่ใช้

| ส่วน | เทคโนโลยี |
|---|---|
| **แอป** | Flutter (Dart), GetX (สถานะ การนำทาง และ Dependency Injection), shadcn_ui, flutter_screenutil |
| **เครือข่าย** | http (เชื่อมต่อ REST API ของ backend) |
| **การชำระเงิน** | flutter_stripe |
| **แผนที่และสื่อ** | flutter_map, YouTube Player, image_picker, url_launcher |

## จุดเด่นทางเทคนิค

- **แยกโค้ดตามฟีเจอร์** แต่ละฟีเจอร์ (ร้านค้า ตะกร้า ชำระเงิน คำสั่งซื้อ ผู้ขาย ผู้ดูแล ฯลฯ) มี Binding, Controller, Repository, Model และหน้าจอของตัวเอง
- **สิทธิ์ตามบทบาท** แอปอ่านบทบาทของผู้ใช้จากโทเค็นแล้วแสดงเมนูและหน้าจอของผู้ขายหรือผู้ดูแลเฉพาะผู้ที่มีสิทธิ์
- **ชำระเงินสองทาง** บัตรผ่าน Stripe และโอนเงินพร้อมอัปโหลดสลิป ซึ่งผู้ดูแลตรวจสอบก่อนยืนยันคำสั่งซื้อ
- **แผนที่แบบโต้ตอบ** แสดงตำแหน่งร้านค้าและเนื้อหาบนแผนที่ด้วย flutter_map
- **ตั้งค่าเซิร์ฟเวอร์ตอน build** ที่อยู่ API ส่งผ่าน `--dart-define` ไม่ฝังไว้ในโค้ด
- **มีเอกสาร API ประกอบ** โฟลเดอร์ `docs/` อธิบาย API ของโปรโมชัน ราคาในตะกร้า การหมดอายุของการชำระเงิน การตรวจสลิป และผู้ดูแลระบบ

## โครงสร้างโปรเจกต์

```
lib/
├── app/          เส้นทาง (routes) ธีม และการตั้งค่า
├── core/         เครือข่าย ค่าคงที่ และบริการกลาง
├── features/     แยกตามฟีเจอร์ (home, shops, cart, checkout, orders, merchant, admin, ...)
│   └── <feature>/{bindings,controllers,models,repositories,views,widgets}
└── shared/       วิดเจ็ตที่ใช้ร่วมกัน
docs/             เอกสาร API ที่แอปเรียกใช้
```

## วิธีรันบนเครื่อง

**สิ่งที่ต้องมี:** Flutter SDK (รุ่นที่รองรับ Dart ตามที่ระบุใน `pubspec.yaml`), Android Emulator หรืออุปกรณ์จริง และ backend ที่รันอยู่ (ใช้พอร์ต 5123)

```powershell
flutter pub get

# ระบุที่อยู่ API ของ backend ตอนรัน
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:5123/api
```

หรือใช้ไฟล์ตั้งค่า:

```powershell
copy env.example.json env.json
flutter run --dart-define-from-file=env.json
```

- Android Emulator ใช้ `10.0.2.2` แทน `localhost` ของเครื่องคุณ
- มือถือจริง ใช้ IP ของคอมพิวเตอร์ในวง LAN เช่น `http://192.168.1.10:5123/api`
- Stripe: ในโค้ด (`lib/main.dart`) ใส่คีย์ทดสอบ (`pk_test_...`) ไว้ ซึ่งเป็น Publishable Key ที่เปิดเผยได้ ควรเปลี่ยนเป็นของบัญชีคุณเอง และห้ามใส่ Secret Key (`sk_...`) ในแอป
